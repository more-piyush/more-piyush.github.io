Question 1: Expressivity of neural networks

Recall that the functional form for a single neuron is given by y = σ(⟨w, x⟩ + b), where x is the input and y is the output. Assume that x and y are 1-dimensional and σ is the step activation: σ(u) = 1 for u > 0 and 0 otherwise. We will use multiple layers of such neurons to approximate pretty much any function f.

(a) Realizing a box function

A box function with height h and width δ is the function f(x) = h for 0 < x < δ and 0 otherwise. Show that a simple neural network with 2 hidden neurons with step activations can realize this function.

single neuron y = σ(⟨w, x⟩ + b), x → input; y → output. σ → step activation σ(u) = 1, u > 0 and 0 otherwise.

Box function with height h and width δ: f(x) = h if 0 < x < δ, 0 otherwise. The box function:

f(x) = hσ(x) − h(σ(x − δ))

hidden layer contains two neurons → two activation function needed.

h1(x) = σ(w1x + b1) = σ(x) ⇒ w1 = 1, b1 = 0
h2(x) = σ(w2x + b2) = σ(x − δ) ⇒ w2 = 1, b2 = −δ
y = v1h1(x) + v2h2(x) = hσ(x) − hσ(x − δ) ⇒ v1 = h, v2 = −h

for x ≤ 0, h1(x) = 0, h2(x) = 0 ⇒ y = h(0) − h(0) = 0. for 0 < x ≤ δ, h1(x) = 1, h2(x) = 0 ⇒ y = h(1) − h(0) = h. for x > δ, h1(x) = 1, h2(x) = 1 ⇒ y = h(1) − h(1) = 0.

Assumption made in reasoning: δ is positive and h is non-zero. output neuron → linear combination, no activation function.

(b) Approximating an arbitrary function

Now suppose that f is any arbitrary, smooth, bounded function defined over an interval [−B, B]. Use part a to show that this function can be closely approximated by a neural network with a hidden layer of neurons.

f → arbitrary, smooth bounded function defined over an interval [−B, B] ⇒ uniform, continuous.

Dividing the domain [−B, B] into small intervals of uniform width Δx = 2B/N with endpoints xk = −B + kΔx.

Lets define a function gA(x) s.t gA(x) = 1 x ∈ A, 0 otherwise. g(xk < x < xk + Δx) equals 1 when x lies in subinterval, otherwise 0. Thus,

f(x) ≈ ∑k=0N−1 f(xk) · g(xk < x < xk + Δx)

Now, each slice g(x) is a box function with height f(xk). From (a), each box function is formed by two neurons with step activation function bk(x) = σ(x − xk) − σ(x − (xk + Δx)). Now, for N such box functions in single hidden layer:

f(x) = ∑k=0N−1 f(xk)[σ(x − xk) − σ(x − xk − Δx)]

As N → ∞, Δx → 0, the approximation → f(x).

(c) Extension to d-dimensional inputs

Do you think the argument in part b can be extended to the case of d-dimensional inputs? If yes, comment on potential practical issues (for example, exponential growth in network size).

Yes, argument extends to d-dimensional inputs (x ∈ ℝd). the domain [−B, B]d can be partioned into small d-dimensional structures of side length δ. The function g can be formed using bounding-2d faces (planes) and then forming 3d slices across the bounding faces, and then approximating the function as weighted sum of slices.

Limitations — Exponential Growth in Network size: Partitioning of d-dimensional domain [−B, B]d into grid with k = 2B/δ subdivisions per dimension. N = kd = [2B/δ]d. Computational Complexity: As dimension d grows, the required number of neurons and parameters grow exponentially.

Question 2: Getting a feel of gradient computation

Suppose that z is a vector with n elements. We would like to compute the gradient of the vector y = softmax(z).

(a) The softmax Jacobian

Softmax Function yi = ezi / ∑k=1n ezk. maps n-dimensional vector z = [z1, z2, z3 … zn]T to a probability distribution vector y = [y1, y2, …, yn]T for component i ∈ {1, 2, … n}.

Jacobian Matrix Jij = ∂yi/∂zj. Using the quotient rule d(u/v) = (u′v − uv′)/v2:

∂yi/∂zj = [ ∂/∂zj(ezi) ∑k=1n ezk − ezi ∂/∂zj(∑k=1n ezk) ] / (∑k=1n ezk)2

partial derivatives: ∂ezi/∂zj = δij ezi; ∂/∂zj(∑k=1n ezk) = ezj. Substituting:

Jij = [δij ezi ∑k=1n ezk − eziezj] / (∑k=1n ezk)2 = δij yi − yiyj
Jij = yi(δij − yj)

(b) Gradient of the cross-entropy loss

cross-entropy loss for target-probability distribution t = [t1, t2, …]T: L = −∑i=1n ti ln yi. using multivariate chain rule, the derivative of the loss L wrt input zj:

∂L/∂zj = ∑i=1n (∂L/∂yi)(∂yi/∂zj)

substituting ∂L/∂yi = −ti/yi and jacobian ∂yi/∂zj = yi(δij − yj):

∂L/∂zj = −∑i=1n (ti/yi) yi(δij − yj) = −∑i=1n ti(δij − yj) = −∑i=1n tiδij + ∑i=1n tiyj = −tj + yj∑i=1n ti

for a probability distribution, ∑i=1n ti = 1, therefore ∂L/∂zj = −tj + yj, i.e. ∇zL = y − t.

Intuitive Explanation: Gradient for zj → difference between the predicted probability yj and ground truth probability tj. If model predicts a higher probability than target (yj > tj) the gradient is positive (∂L/∂zj > 0). In gradient descent, updating zj ← zj − η ∂L/∂zj reduces zj, effectively decreasing yj. If model underpredicts (yj < tj), the gradient is negative (∂L/∂zj < 0), causing gradient descent to increase zj, increasing yj. For yj = tj, predictions match target posibilities, gradient vanishes ∇zL = 0, no update.

Question 3: The structure of neural networks

Use the FashionMNIST dataset and a dense neural network with three hidden layers of sizes 256,128,64. (a) A normal network: ReLU activations and standard random initialization; (b) a linear neural network: exactly the same architecture, but remove all ReLU activations; and (c) zero-init: the first ReLU network, but initialize every weight and bias to zero. Keep the dataset, optimizer, learning rate, batch size, and number of training epochs the same across all three experiments.

Three experiments, same architecture (784 → 256 → 128 → 64 → 10), same optimizer/lr/batch size/epochs: (a) Normal — ReLU activations, standard random initialization; (b) Linear — same architecture, ReLU activations removed (identity between layers); (c) Zero-init — same as (a) but every weight and bias initialized to zero.

fashionmnist_relu_vs_linear_vs_zeroinit.ipynb

class MLP(nn.Module):
    def __init__(self, hidden_sizes=(256, 128, 64), use_relu=True, zero_init=False):
        super().__init__()
        sizes = [28 * 28] + list(hidden_sizes) + [10]
        layers = []
        for i in range(len(sizes) - 1):
            layers.append(nn.Linear(sizes[i], sizes[i + 1]))
            is_last = (i == len(sizes) - 2)
            if use_relu and not is_last:
                layers.append(nn.ReLU())
        self.net = nn.Sequential(*layers)
        if zero_init:
            self._zero_init()

    def _zero_init(self):
        for m in self.net:
            if isinstance(m, nn.Linear):
                nn.init.zeros_(m.weight)
                nn.init.zeros_(m.bias)

Results

Interpretation

The prediction are as expected, but what surprised me was how the linear unit still trains and improves its learning but just worse loss than the ReLU network and the zero Initialization network doesn't just fail but gives a Flat line with exact same loss in each iteration.

Why doesn't stacking more linear layers give a linear network ReLU expressive power? If layer 1 computes W1x + b1 and layer 2 computes W2(·) + b2 then together they compute W2W1x + (W2b1 + b2). So stacking linear layer ultimately collapse into single linear layer.

Explaining the behaviour of zero Initialized network: when every weight and bias is 0 (even constant), every neuron computes the same outputs, so network's prediction is same for each input so their probability is same. During backpropagation, depends on neuron activation, which is 0, so the gradient remain same (0), thus network get same update (0), so the network maintains a symmetrical behaviour throughout training, resulting in a Flat line stuck permanently.

Why do non-linearity and initialization matter? Non-Linearity overcomes the problem of linear network collapsing into one linear function, and allowing the extra layers to learn more from data and achieve better accuracy and random initialization ensures that each neuron starts different and learns different features.
