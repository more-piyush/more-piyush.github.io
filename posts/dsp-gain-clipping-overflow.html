Driving a second-order recursive filter with a unit impulse and sending the output to PyAudio as 16-bit samples — what happens when the gain is set too high, and how to choose a safe gain from the impulse response.

D3Q4.py

Fs = 8000
T = 1
N = T*Fs


a1 = -1.9
a2 = 0.998

y1 = 0.0
y2 = 0.0
gain = 100000.0

D3Q4.py

for n in range(0, int(N)):

    if n == 0:
        x0 = 1.0
    else:
        x0 = 0.0

    y0 = x0 - a1 * y1 - a2 * y2

    y2 = y1
    y1 = y0

Question 4: Overflow and clipping

Setting gain to high value causes output value to exceed the range of 16-bit signed integer (215 − 1). When struct.pack('h', …) receives value outside range, It raises runtime error because value cannot fit into 2 bytes.

This runtime overflow error is avoided by clipping the signal using if statement to check if value exceeds the minimum or maximum bounds and forcing it within limits.

D3Q4.py

    output_value = gain * y0

    if output_value > 32767:
        output_value = 32767
    elif output_value < -32768:
        output_value = -32768


    output_string = struct.pack('h', int(output_value))
    stream.write(output_string)

Effect on the sound?

Clippings squares off peaks of waveforms, producing harmonic distortions, which make sounds sharper, buzzy compared to original tone.

Question 5: Choosing the gain from the impulse response

Impulse response   h(n) = rn cos(ω1n) u(n)
Z Transform   H(z) = (1 − r cos(ω1) z−1) / (1 − 2r cos(ω1) z−1 + r2z−2)

comparing with,

H(z) = (b0 + b1z−1 + b2z−2) / (1 + a1z−1 + a2z−2)
b0 = 1,   b1 = −r cos(ω1),   b2 = 0

Since |h(n)| ≤ 1 for all n, the maximum value occurs at n = 0 where h(0) = 1. To ensure signal doesn't exceed 215 − 1, using if condition, gain is set to 32767.
