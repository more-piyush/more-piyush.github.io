Driving a second-order recursive filter with a unit impulse and sending the output to PyAudio as 16-bit samples — what happens when the gain is set too high, how clipping prevents the overflow, and what clipping does to the sound.

What happens when the gain is too high?

Setting gain to high value causes output value to exceed the range of 16-bit signed integer (215 − 1). When struct.pack('h', …) receives value outside range, It raises runtime error because value cannot fit into 2 bytes.

D3Q4.py

Fs = 8000
T = 1
N = T*Fs


a1 = -1.9
a2 = 0.998

y1 = 0.0
y2 = 0.0
gain = 100000.0

D3Q4.py

for n in range(0, int(N)):

    if n == 0:
        x0 = 1.0
    else:
        x0 = 0.0

    y0 = x0 - a1 * y1 - a2 * y2

    y2 = y1
    y1 = y0

How does clipping help?

This runtime overflow error is avoided by clipping the signal using if statement to check if value exceeds the minimum or maximum bounds and forcing it within limits.

D3Q4.py

    output_value = gain * y0

    if output_value > 32767:
        output_value = 32767
    elif output_value < -32768:
        output_value = -32768


    output_string = struct.pack('h', int(output_value))
    stream.write(output_string)

What does clipping do to the sound?

Clippings squares off peaks of waveforms, producing harmonic distortions, which make sounds sharper, buzzy compared to original tone.
