Training a small decoder-only transformer from scratch on TinyStories, a dataset of short, simple stories — the model, a correctness check that it can memorize one batch, a 25-million-token training run on a laptop GPU, and how its generated stories change from random fragments to readable text.

What does the model look like?

Architecturedecoder-only transformer, pre-LayerNorm residual blocks, causal self-attention, GELU MLP (4× width)
Blocks / width / heads6 / 384 / 6 (head dimension 64)
Context length256 tokens, learned positional embeddings
Outputlogits over the vocabulary at every position (softmax gives the next-token distribution); token embedding and output projection share weights
Vocabulary8,192 byte-level BPE tokens trained on the training split, EOS between stories
Parameters13,891,584
Data100,000 training stories (21,611,495 tokens) and 2,000 validation stories (382,835 tokens; fixed 32,768-token evaluation prefix), exact duplicates removed
Lossaverage next-token cross-entropy

The attention calculation is written out explicitly rather than calling a fused kernel. The triangular mask is applied before softmax. Softmax is evaluated in FP32 for numerical stability, then cast back.

    def forward(self, x):
        B, T, D = x.shape
        q, k, v = self.qkv(x).chunk(3, dim=-1)
        q, k, v = [t.reshape(B, T, self.heads, self.head_dim).transpose(1, 2)
                   for t in (q, k, v)]
        scores = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_dim)
        scores = scores.masked_fill(~self.allowed[:T, :T], float("-inf"))
        weights = F.softmax(scores.float(), dim=-1).to(v.dtype)
        out = self.attn_drop(weights) @ v
        out = out.transpose(1, 2).contiguous().reshape(B, T, D)
        return self.out_drop(self.proj(out))

class Block(nn.Module):
    def __init__(self, c):
        super().__init__()
        self.norm1 = nn.LayerNorm(c.d_model)
        self.attn = CausalAttention(c)
        self.norm2 = nn.LayerNorm(c.d_model)
        self.mlp = nn.Sequential(nn.Linear(c.d_model, 4*c.d_model), nn.GELU(),
                                 nn.Linear(4*c.d_model, c.d_model), nn.Dropout(c.dropout))
    def forward(self, x):
        x = x + self.attn(self.norm1(x))
        return x + self.mlp(self.norm2(x))

How are the stories turned into training examples?

Byte-level BPE starts with all byte symbols, allowing arbitrary text without a large word vocabulary. EOS is appended once per story. A length T+1 slice produces x = slice[:-1] and y = slice[1:], and training windows are randomly sampled from the training token stream.

def get_batch(tokens, batch_size, context, rng):
    assert len(tokens) > context
    starts = rng.integers(0, len(tokens) - context, size=batch_size)
    z = np.stack([tokens[s:s+context+1] for s in starts]).astype(np.int64)
    x = torch.from_numpy(z[:, :-1].copy()).to(DEVICE)
    y = torch.from_numpy(z[:, 1:].copy()).to(DEVICE)
    return x, y

Can the model memorize a single batch?

Full-size model (dropout off, AdamW lr 1e-3, FP32) was trained on one fixed batch of 4 × 256 = 1,024 target tokens for 300 updates. Training loss went from 9.063 to 0.0046.

What did I expect before training?

25 M tokens → less than 2 tokens per parameter for 13.9 M parameter model, not very compute efficient training, so expecting under-training.

A random model spread probability evenly over 8192 tokens, so loss should be ln(8192) = 9.01.

The model should learn random words and subfragment first, then common words, punctuation, then local grammar and story structure.

What improves, and what errors remain?

Before training: random vocabulary items and fragments, no relation with prompt, consistent with near uniform output distribution.

Mid training (12.5 M tokens, val. loss 2.5): real sentences, punctuations, quotation, paragraph breaks. Continuation relevant to prompts. Errors: character mixup, repetition, broken grammar ("it had not to go away"), odd events ("ran to the sun").

End of training (val. loss 2.2): smoother text, emotion understanding, dialogue alternate correct between speakers. Errors that remain:

  • Odd events — ("ball broke into its mouth")
  • Confused references — ("She told Lily that Lily was sad")
  • model can't keep track of who is who

Training loss sits above validation loss:

  • measured with dropout on
  • validation loss uses current weight with dropout off

Why is the validation loss 2.2 and not 1.3 – 1.5?

  • conservative learning rate
  • dropout 0.1 slow fitting
  • curve was still falling
