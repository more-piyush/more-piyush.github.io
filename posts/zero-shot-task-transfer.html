Notes on Zero-Shot Task Transfer — a meta-learning algorithm that regresses model parameters for tasks with no ground truth.

Abstract

A novel meta learning algorithm that regresses model parameters for zero-shot tasks (no ground truth). In order to adapt to novel zero-shot tasks, the meta learner learns from the model parameters of known tasks (w/ ground truth) and correlation between them.

Model evaluation of the model is carried out over four tasks as zero shot: surface normal, room layout, depth and camera pose estimation, chosen based on acquisition complexity and complexity associated with the learning process. The authors have conducted extensive research to study the various choices of the methodology, and have shown how the proposed method can be utilized in transfer learning.

Introduction

The major driving force behind computer vision is availability of large amounts of curated labeled data. Effective models that work in practice require a very large labeled data, which isn't practical as they are expert demanding and labor intensive. Due to its expensive nature, practitioners avoid such tasks or carry out in lesser amounts of data which leads to poor performing models.

Authors have built an alternative approach that can obtain model parameters for tasks without any labeled data.

Cognitive studies show results where a subject could adapt to new scenarios by correlating with experience, without any explicit supervision. Understanding this the authors propose a meta-learner that learns from the Encoder-Decoder parameters of known tasks (w/ ground truth) and their correlation to the novel task.

Formally, we have the knowledge of m known tasks { T1, T2, …. Tm }, a meta-learner F, utilized to derive the parameters for the T(m+1) novel task. The Encoder-Decoder Subscripts are forementioned as Te(i) and Td(i).

However, with no knowledge of the correlation between the tasks, it isn't probable for the meta-learner to learn, as it could map on any point on the meta-manifold. Hence the correlation between the known tasks and novel tasks is considered as an additional input.

There are different notions of how correlation between the task could be obtained. In this work, the authors have utilized the approach of wisdom-of-crowd. Harvesting task correlation knowledge from the crowd is fast, cheap, and brings domain knowledge. High-fidelity aggregation of crowd votes is used to integrate the task correlation between known and zero-shot tasks in the model.

Authors have leveraged task correlation for the objectives listed:

  1. Extrapolate parameters to a zero-shot task, for which no labeled data is available
  2. To adapt to a new task without requiring any target labeled data
  3. Used to learn multiple tasks simultaneously

Author contributions can be summarized as

  1. A novel methodology to infer zero-shot task parameters used to solve tasks with no labeled data
  2. Methodology can scale to solving multiple zero-shot tasks simultaneously, provides near state-of-the-art models with a smaller set of known tasks
  3. How the method can be used in transfer learning setting

Related Works

Transfer Learning: Reusing supervision, where an already learned model of a task is fine-tuned to a target task.

Multi-task Learning: Multi-task learning learns multiple tasks simultaneously with a view of task generalization. Some methods assume a prior and then iterate to learn a joint space of tasks, others don't use a prior but learn a joint space of tasks during the process of learning. Distributed Multi-task learning methods focus on the same objectives when the tasks are distributed over the network. However, there is an explicit need of having labeled data for all the tasks. It can't solve zero-shot tasks w/o labeled data.

Domain Adaptation: Primary focus of domain adaptation is to transfer domain knowledge from a data-rich domain to a domain with limited data. Learning domain-invariant features requires domain alignment. Such matching is achieved through use of an auto-encoder, by clustering, by using GANs. The authors have proposed a generalizable framework that can learn models for a novel task from the knowledge of available tasks and their correlation with novel tasks.

Meta-Learning: Earlier efforts on meta-learning assume that task parameters lie on a low dimensional subspace, share a common probabilistic prior, however, these efforts are targeted only to achieve knowledge transfer among known tasks and tasks with limited data. Recent meta-learning approaches consider all task parameters as input signals to learn a meta manifold that helps few shot learning, transfer learning and domain adaptation. However, the meta manifold learned by these methods isn't explicit enough to extrapolate parameters of zero-shot tasks. The authors method relaxes the need for ground truth for zero-shot tasks, by leveraging task correlation among known tasks and novel zero-shot tasks.

Learning with Weak Supervision: In this method, task supervision is a form of weak supervision. Weak supervision is harvested from knowledge bases, domain heuristics, ontologies, rules of thumb, decisions of weak classifiers or obtained using crowdsourcing.

Methodology

The primary objective is to learn a meta-learning algorithm that regresses neatly optimal parameters of a novel task for which no ground truth is available. The meta learner seeks to learn from the model parameters of known tasks to adapt to novel zero-shot tasks.

Formally, consider K tasks, i.e. T = { T1, T2, ….. , Tk } each of whose model parameters lie on a meta manifold M of task model parameters. We have ground truth available for first m tasks, i.e. { T1, … , Tm } with their corresponding model parameters Ot(i). We have no knowledge of the ground truth for the zero-shot tasks {T(m+1) , …. , Tk }.

The objective function F(.) is designed as a network of m branches, each with parameters (weights) { W1, W2, … , Wm } reply, aren't coupled with the initial layers but later combined in a W(common) block that regresses encoder and decoder parameters.

Dividing the function F(.) into parts, W(initial) and W(common) is driven by intuition, where the initial layers transform the individual task model parameter into a suitable representation space and later layers parameterized by W(common) capture relationship between the tasks and contribute towards regressing the encoder and decoder parameter.

Training: The meta network is trained on the objective function in two modes: a self mode and transfer mode for each task. Given a known task Ti, training in self mode implies updating of weights Wi and W(common) alone. While, training in the transfer mode implies updation of weights and W(common) of F(.). Self mode is similar to training a standard autoencoder, where F(.) learns to project the model parameter near the given model parameter (learned from ground truth) .

In transfer mode, a set of model parameters of tasks (other than τj) attempt to map the position of learned θτj, near the given model parameter θτj on the meta manifold. The transfer mode is essential to be able to regress the model parameters of a task, given the model parameters of other tasks. At the inference time, the objective function F(.) operates in transfer mode.
