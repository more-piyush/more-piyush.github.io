From first-order difference equations to a second-order system whose poles set the shape of its impulse response — and how those pole positions turn into filter coefficients for a real-time resonator.

What is a first-order difference equation?

a0y(n) + a1y(n−1) = b0x(n) + b1x(n−1),   n ∈ ℤ

x(n) → [ ] → y(n)

WLOG a0 = 1

y(n) = b0x(n) + b1x(n−1) − a1y(n−1)

If x(−1) = y(−1) = 0, Then we can proceed.

H(z) = (b0 + b1z−1) / (1 + a1z−1)    Transfer function
Hf(ω) = ∑n h(n)e−jnω = DTFT{h}   where h is the impulse response.
= H(ejω)   uses bi & ai.

What does a second-order system look like?

y(n) = b0x(n) + b1x(n−1) + b2x(n−2) − a1y(n−1) − a2y(n−2)
H(z) = (b0 + b1z−1 + b2z−2) / (1 + a1z−1 + a2z−2) = B(z)/A(z)
= (b0z2 + b1z + b2) / (z2 + a1z + a2) = b0(z − z1)(z − z2) / ((z − p1)(z − p2))

How do the poles shape the impulse response?

p1 = rejω1,   p2 = re−jω1
h(n) = A0δ(n) + C1p1nu(n) + C1*(p1*)nu(n)

u : step fcn. C1 is determined via partial frac. expansion. C1 = Rejθ

h(n) = [Rejθ(rejω1)n + Re−jθ(re−jω1)n]u(n)
= Rrn[ej(θ + ω1n) + e−j(θ + ω1n)]u(n)
= 2Rrn cos(ω1n + θ)u(n)

pole radius (r) and angle (ω1) determines the behavior of the imp resp.

How do the poles set the filter coefficients?

H(z) = 1 / (1 + a1z−1 + a2z−2) = z2 / (z2 + a1z + a2)
= z2 / ((z − rejω1)(z − re−jω1))
→ z2 − z(rejω1 + re−jω1) + r2e−jω1e+jω1
→ z2 − z2r cos(ω1) + r2
= z2 + a1z + a2
a1 = −2r cos(ω1)     a2 = r2
a = [a0  a1  a2]
a = [1  -2 r cos(om1)   r^2]

How do you implement a second-order filter?

Impulse response   h(n) = rn cos(ω1n) u(n)
Z Transform   H(z) = (1 − r cos(ω1) z−1) / (1 − 2r cos(ω1) z−1 + r2z−2)

comparing with,

H(z) = (b0 + b1z−1 + b2z−2) / (1 + a1z−1 + a2z−2)
