Classifying FashionMNIST clothing images with Vision Transformers instead of a dense network — why attention can be made linear in the number of tokens, how a ViT turns an image into tokens, and what happens across 18 models that vary the patch size, depth and number of heads.

An earlier post trained a dense network (784 → 256 → 128 → 64 → 10) on the same dataset with the same pixel normalization.

Why is self-attention quadratic, and can it be made linear?

Let sequence length be T, each query and key has dimension d, each value has dimension dv.

In self-attention layer each query is compared with all T keys which creates T × T score matrix, computing those scores requires O(T2d) operations, so cost grows quadratically with sequence length.

In linear attention, the exponentials are dropped and attention score between query qi and key kj is qiTkj. The output token i is

yiT = ∑j=1T (qiTkj) vjT  /  ∑j=1T qiTkj

solving numerator,

∑j=1T (qiTkj) vjT = qiT ∑j=1T kjvjT

solving denominator,

∑j=1T qiTkj = qiT (∑j=1T kj)

By using matrix multiplication associativity, we can compute

S = KTV ∈ ℝd×dv,    z = KT·1 ∈ ℝd

1 → all vector are ones. S and z don't depend on token i. Output is

yiT = qiTS / qiTz

avoiding the formation of T × T attention matrix QKT.

  • computing cost of S → O(Tddv)
  • computing cost of z → O(Td)
  • computing qiTS and qiTz for all token costs O(Tddv + Td)
  • normalizing output rows costs O(Tdv)

Total runtime

O(Tddv + Td + Tdv) = O(T)

feature dimensions d and dv → fixed independently of T.

How does a Vision Transformer read an image?

28×28 images → 49 patches (4×4) or 16 patches (7×7), plus a learnable [CLS] token. Patchify cuts each image into non-overlapping P×P patches (with unfold) and maps each flattened patch to a 96-dim token. A learnable [CLS] token is prepended, learned position embeddings are added, and the [CLS] output after the last block is classified.

Q2_ViT_FashionMNIST.ipynb

class Patchify(nn.Module):
    def __init__(self, patch, d_model):
        super().__init__()
        self.patch = patch
        self.proj = nn.Linear(patch * patch, d_model)
    def forward(self, x):                                   # x: (B, 1, 28, 28)
        p = F.unfold(x, kernel_size=self.patch, stride=self.patch)   # (B, P*P, N)
        return self.proj(p.transpose(1, 2))                 # (B, N, d_model)

Attention is softmax(QKT/√d)·V per head, computed with PyTorch's fused scaled_dot_product_attention kernel (no mask, since every patch may attend to every other patch).

Q2_ViT_FashionMNIST.ipynb

class SelfAttention(nn.Module):
    def __init__(self, d_model, heads, dropout):
        super().__init__()
        assert d_model % heads == 0
        self.heads, self.head_dim = heads, d_model // heads
        self.qkv = nn.Linear(d_model, 3 * d_model)
        self.out = nn.Linear(d_model, d_model)
        self.dropout = dropout
    def forward(self, x):
        B, N, D = x.shape
        q, k, v = self.qkv(x).reshape(B, N, 3, self.heads, self.head_dim).permute(2, 0, 3, 1, 4)
        # Same as softmax(q @ k^T / sqrt(head_dim)) @ v with dropout on the weights, in one fused kernel.
        # No causal mask: every patch can attend to every other patch.
        mixed = F.scaled_dot_product_attention(q, k, v, dropout_p=self.dropout if self.training else 0.0)
        return self.out(mixed.transpose(1, 2).reshape(B, N, D))

class EncoderBlock(nn.Module):
    def __init__(self, d_model, heads, mlp_dim, dropout):
        super().__init__()
        self.norm1, self.attn = nn.LayerNorm(d_model), SelfAttention(d_model, heads, dropout)
        self.norm2 = nn.LayerNorm(d_model)
        self.mlp = nn.Sequential(nn.Linear(d_model, mlp_dim), nn.GELU(), nn.Dropout(dropout),
                                 nn.Linear(mlp_dim, d_model), nn.Dropout(dropout))
    def forward(self, x):
        x = x + self.attn(self.norm1(x))
        return x + self.mlp(self.norm2(x))

What did I expect before training?

4×4 Patches and 7×7 patches. For 28 × 28 image size, 4×4 patches has 49 tokens whereas 7×7 patches need 16 tokens. Attention cost is square of token count, and MLP cost grows N, so 4×4 cost more. The 7×7 patch is small enough to learn clothing shapes. So, 4×4 patch won't have much accuracy gain, but much higher cost.

Deeper models optimize slowly, so will have slight improvements beyond 4 to 6 layers.

For a fixed width, more heads simply implies heads with smaller size with same number of parameters, so there will be small effect.

Unlike CNNs, ViT don't exploit the concept of locality and spatial invariance, so ViT will have an accuracy about CNNs, not more than them.

What do the results say?

All models lie in range 88.27% – 89.41% with a distribution of only 1.1, most of these errors can be associated as standard error.

The mean accuracy of 4×4 patches is 88.81% v/s 88.88% of 7×7 patches while the compute cost takes 4×4 patches takes 339s v/s 7×7 patches 115s, thus 4×4 patches isn't reasonable for the cost.

  • 4 layers is lowest for both patches
  • 6 layers improves a little
  • 8 layer remains stagnant

Heads don't change the parameter count, heads just partition the dimension.

Deeper model start slower, model are undertrained and more epochs could improve performance a bit.
