Notes on the mathematics behind factor graphs — from MAP inference as a nonlinear least squares problem, through direct linear solvers, to nonlinear optimization.

MAP Inference and Nonlinear Least Squares

XMAP = argmax φ(x) = argmax ∏ φi(xi)
φi(xi) ∝ exp{ −½ ‖ hi(xi) − zi ‖2Σi }
XMAP = argmin ∑ ‖ hi(xi) − zi ‖2Σi  →  minimize a sum of non-linear least squares

φi(xi) → factor graph potentials. hi(·) → measurement functions.

Linearizing the Measurement Functions

Linearize all measurement functions hi(·) in non-linear least squares objective function using Taylor Expansion:

hi(xi) = hi(xi0 + Δi) ≈ hi(xi0) + HiΔi

where measurement jacobian Hi, multivariate partial derivative of hi(·) at a given linearization point xi0:

Hi ≜ ∂hi(xi) / ∂xi |xi0

Δi ≜ xi − xi0 State Update Vector.

Substituting Taylor series expansion into non-linear least square expression to obtain a linear least square problem in state update vector Δ:

Δ = argmin ∑ ‖ hi(xi0) + HiΔi − zi ‖2Σi = argmin ∑ ‖ HiΔi − { zi − hi(xi0) } ‖2Σi

zi − hixi0 is prediction error at linearization point (difference between actual and predicted measurement).

Change of Variables (Whitening)

Change of variables → Drop covariance matrices Σi → w/ Σ1/2 the matrix square root of Σ.

‖e‖2Σ ≜ eTΣ−1e = (Σ−1/2e)T(Σ−1/2e) = ‖ Σ−1/2e ‖22

eliminate the covariance Σi by pre-multiplying by Jacobian Hi and prediction error in each term with Σi−1/2:

Ai = Σi−1/2 Hi
bi = Σi−1/2 (zi − hi(xi0))

process — form of whitening → dividing each term by the measurement std. deviation σi. Eliminates the units of measurement so different rows can be combined into single cost function.

Standard Least Squares Problem

Δ* = argmin ∑ ‖ AiΔi − bi ‖22 = argmin ‖ AΔ − b ‖22

A and b → obtained by collecting all whitened Jacobian matrices Ai and whitened prediction errors bi into one large matrix A and right hand side vector b.

Jacobian A is a large but sparse matrix with block structure that mirrors the structure of underlying factor graph.

Direct Method for Least Squares

For full rank matrix (m×n) A, with m≥n, the unique least square solution Δ* = argmin ‖AΔ − b‖22 can be found by solving the normal equation:

(ATA) Δ* = ATb

done by factoring information matrix Λ, defined and factored as:

Λ ≜ ATA = RTR

above, Cholesky Triangle R is an upper triangular n×n matrix and computed using Cholesky Factorization, variant of LU factorization for symmetric positive definite matrices. Δ* can be found by solving:

RTy = ATb  and  RΔ* = y  by forward-backward substitution

For dense matrices, Cholesky Factorization requires (n3/3) flops and entire algorithm, including computing half symmetric ATA, requires (m + n/3)n2 flops. Also use LDL factorization, a variant of Cholesky Decomposition that avoids compution of square roots.

QR Factorization

Alternative to Cholesky Factorization, more accurate and more numerically stable → proceed via QR Factorization → works w/o computing information matrix Λ. Instead compute QR Factorization of A itself along with its corresponding RHS:

A = Q [ R ; 0 ]    [ d ; e ] = QTb

Q — m×m orthogonal matrix, d ∈ ℝn, e ∈ ℝm×n, R — same upper triangle Cholesky Triangle.

Preferred Method: Factorizing a dense matrix A is to compute R column by column (left to right). For each column j, all non-zero elements below diagonal are zeroed out by multiplying A on the left with Household reflection matrix Hj. After n iterations, A is completely factorized:

Hn … H2 H1 A = QTA = [ R ; 0 ]

Orthogonal Matrix Q → not formed. Transformed RHS QTb → computed by appending b as an extra column to A. Because Q factor is orthogonal:

‖ AΔ − b ‖22 = ‖ QTAΔ − QTb ‖22 = ‖ RΔ − d ‖22 + ‖e‖22

‖e‖22 → least squares sum of residuals. Least Squares solution Δ* can be obtained by solving the triangular system RΔ* = d via back substitution.

The cost of QR is dominated by cost of Household Reflections, which is 2(m − n/3)n2. Comparing w/ Cholesky, both algorithms require O(mn2) operations when m>>n; but QR factorization is slower by a factor of 2.

Note: Upper Triangular Factor R obtained using QR Factorization is same as obtained by Cholesky Factorization:

ATA = [R ; 0]T QTQ [R ; 0] = RTR  (using Q is orthogonal)

Efficient algorithm for factorizing large sparse matrix for both QR and Cholesky variants → depends on amount of non-zeroes and sparsity structure → cost of Sparse factorization can be far lower than its dense equivalent. Software Implementation → CHOLMOD, SuiteSparseQR.

In practice, sparse Cholesky and LDL Factorization outperform QR Factorization on sparse problems as well, not just a constant factor. Optimization problem associated with SLAM (stated in terms of sparse linear algebra) comes down to factorizing either the information matrix Λ or Jacobian matrix A into square root form.

Step by Step Calculation

Cholesky Factorization — fit straight line y = mx + c to data points (0,1); (1,2); (2,2).

Matrix Setup, system of linear equation for three points:

c·1 + m·0 = 1
c·1 + m·1 = 2
c·1 + m·2 = 2

converts to matrix form AΔ = b:

[ 1 0 ; 1 1 ; 1 2 ] [ c ; m ] = [ 1 ; 2 ; 2 ]

Cholesky method → calculating information matrix (ATA) & Right Hand side Vector (ATb):

ATA = [ 1 1 1 ; 0 1 2 ] [ 1 0 ; 1 1 ; 1 2 ] = [ 3 3 ; 3 5 ]
ATb = [ 1 1 1 ; 0 1 2 ] [ 1 ; 2 ; 2 ] = [ 5 ; 6 ]

Decompose matrix [ 3 3 ; 3 5 ] into upper triangular matrix R such that RTR = A, R = [ R11 R12 ; 0 R22 ]:

R112 = 3 ⇒ R11 = √3
R11R12 = 3 ⇒ R12 = 3/√3 = √3
R122 + R222 = 5 ⇒ R22 = √(5−3) = √2
R = [ √3 √3 ; 0 √2 ]

Forward Substitution, RTy = ATb, intermediate vector y = [y1, y2]T:

√3 y1 = 5 ⇒ y1 = 5/√3
√3 y1 + √2 y2 = 6 ⇒ y2 = 1/√2
y = [ 5/√3 , 1/√2 ]

Solve Triangular System RΔ = y:

c√3 + m√3 = 5/√3
m√2 = 1/√2 ⇒ m = ½
c√3 + √3/2 = 5/√3 ⇒ c = 7/6

QR Factorization — solving AΔ = b for the line y = mx + c passing through (1,0); (1,2); (2,2). [A = [1 0 ; 1 1 ; 1 2], b = [1 ; 2 ; 2]] → factor A into Q (orthogonal unit vectors) and R (upper triangular). Computers usually utilize "Household reflections" (faster for machines), but for mathematical understanding we use Gram-Schmidt process.

Columns of A as vectors: v1 = [1 1 1]T, v2 = [0 1 2]T. Turn v1 and v2 into perpendicular unit vectors q1 and q2.

Find q1 (Normalize first column). Length of v1 = √(12+12+12) = √3:

q1 = v1 / ‖v1‖ = [ 1/√3 ; 1/√3 ; 1/√3 ]

Find q2 (Remove shadows of q1 from v1). First, find projection of v2 in direction of q1:

proj = (v2 · q1) = ( 0·1/√3 + 1·1/√3 + 2·1/√3 ) = √3

Subtract projection from v2 to get perpendicular P2:

P2 = v2 − (√3) q1 = [0 ; 1 ; 2] − [1 ; 1 ; 1] = [−1 ; 0 ; 1]

Normalize P2 to get q2. Length of P2 = √((−1)2+(0)2+(1)2) = √2:

q2 = P2 / ‖P2‖ = [ −1/√2 ; 0 ; 1/√2 ]
Q = [ 1/√3 −1/√2 ; 1/√3 0 ; 1/√3 1/√2 ]

Form matrix R → used to build the original columns using new bases. R11 — length of column 1 = √3; R12 — projection of column 2 onto q1 = √3; R22 — length of perpendicular part of column 2 = √2:

R = [ √3 √3 ; 0 √2 ]

Transform the RHS (QTb). Transform target vector b by multiplying QT, creates vector d used in back substitution:

d = QTb = [ 1/√3 1/√3 1/√3 ; −1/√2 0 1/√2 ] [ 1 ; 2 ; 2 ] = [ 5/√3 ; 1/√2 ]

Solve Triangular System RΔ = d:

c√3 + m√3 = 5/√3
m√2 = 1/√2 ⇒ m = 0.5
c√3 = 5/√3 − √3/2 ⇒ c = 7/6

Non-Linear Optimization of MAP Inference

Non-linear least squares problem → can't be solved directly → requires an iterative solution starting with suitable initial estimate. Algorithms → differ in how they locally approximate the cost function and how they find an improved estimate on local approximation.

Cost Function:

g(x) ≜ ∑ ‖ hi(xi) − zi ‖2Σi

corresponds to non-linear factor graphs derived from measurements along with prior densities on some or all unknowns.

Basic Structure of Algorithms: Start from an initial estimate x0. In each iteration, an update step is calculated Δ and applied to obtain next estimate xt+1 = xt + Δ. Process ends when certain convergence criteria are reached, such as change falling below small threshold.

Steepest Descent

Steepest Descent (SD) or gradient descent uses direction of steepest descent at the current estimate to calculate the following update step:

Δsd = −α ∇g(x) |x=xt

negative gradient → identify the direction of steepest descent. For Non-linear least squares objective function, we compute Jacobian A to locally approximate g(x) ≈ ‖A(x−xt) − b‖22 and obtain exact gradient at the linearization point xt:

∇g(x) |x=xt = −2ATb

step size α → carefully choosen to balance safe updates & reasonable convergence speed. SD → simple algorithm but suffer from slow convergence near the minimum.

Gauss-Newton

Gauss Newton (GN) provides faster convergence by using 2nd order update. GN exploits special structure of non-linear least squares problem to approx. the Hessian by the square of Jacobian as ATA. GN update step is obtained by solving:

(ATA) Δ* = ATb  ⇒  ATA Δgn = ATb

by methods such as Cholesky or QR Factorization. For a well behaved objective function, and good initial estimate, Gauss Newton exhibits nearly quadratic convergence. If Quadratic is poor, GN step can lead to new estimate that is further from minimum and subsequent divergence.

Levenberg-Marquardt

LM Algorithm allows iterating multiple times to convergence while controlling in which region one is willing to trust quadratic approximation made by Gauss Newton. Hence, method is often called Trust Region Method.

To compute advantages of both SD and GN methods, Levemberg proposed to modify the equation (ATA)Δ* = ATb by adding non-negative constant λ ∈ ℝ+ ∪ {0} to diagonal:

(ATA + λI) Δlb = ATb

Note that for λ = 0 we obtain GN and for large λ, approx. obtaining Δ* ≈ (1/λ) ATb, an update in negative gradient direction of cost function g(x). LM → blends between Gauss Newton and Steepest Descent Methods.

Marquardt → proposed considering the scaling of diagonal entries to provide faster convergence:

(ATA + λ diag(ATA)) Δlm = ATb

modification → larger steps in steepest descent direction if the gradient is small because there the inverse of diagonal enteries will be large. Conversely, in steep direction of objective function the algorithm become more cautious and takes smaller steps.

Levenberg-Marquardt Algorithm (quadratic cost function g(), init. estm. x0):

1  function LM(g(), x⁰)
2  λ = 10⁻⁴
3  t = 0
4  repeat
5      A, b  ← linearize g(x) at xᵗ
6      Δ    ← solve (AᵀA + λ diag(AᵀA))Δ = Aᵀb
7      if g(xᵗ + Δ) < g(xᵗ) then
8          xᵗ⁺¹ = xᵗ + Δ            ▸ accept update
9          λ ← λ/10
10     else
11         xᵗ⁺¹ = xᵗ                ▸ reject update
12         λ ← λ * 10
13     t ← t+1
14 until convergence
15 return xᵗ                     ▸ return latest estimate

Detailed Explanation of LM Algorithm → Trying to find the lowest point in dark, hilly valley (minimizing error). Two ways to walk:

  1. The safe way (Gradient Descent) — take small steps straight downhill, slow but gauranteed to get you lower eventually.
  2. The Fast Way (Gauss Newton) — Assume valley is a perfect bowl shape and try to jump straight to the bottom. extremely fast but if ground isn't a bowl, you might jump of cliff.

Levenberg Marquardt Algorithm → Smart hybrid. Switches between these two methods automatically using "damping" parameter λ.

Setup (Lines 1-3): cost function g() (error we want to minimize) and initial guess x0. Initialization: set λ = 10−4 (trust knob). Small number → be agressive (fast way); Large number → be careful (safe way).

Loop (Line 4): Repeat the following process until we find solution (convergence).

Math and Move (Line 5&6): Linearize — algorithm looks at the slope of ground right where we are standing (calculating derivatives / jacobian). Solve for Δ — calculate potential step. If λ is high → acts like gradient descent (small, safe steps). If λ is low → acts like Gauss-Newton (Fast, agressive jumps).

Is this better? Check (Line 7): Algorithm asks "If I take step Δ, is the new error lower than current error?" (g(xt + Δ) < g(xt)).

Success (Lines 8-9): Yes, the error is lower. Accept Update - Take the step (xt+1 = xt + Δ). Get Bolder - decrease λ (divide by 10), since the last agressive worked, we try to be even more agressive and faster next time.

Failure (Lines 10-12): No, the error got worse. Reject Update - We don't move, stay at xt. More careful - increase λ (multiply by 10), bowl assumption "failed", so we need to switch closer to gradient descent (safe mode) to find better path.

Result: changes become tiny (convergence), we return to final position xt.

Difference between GN and LM: LM rejects updates that would lead to higher sum squared residuals. A rejected update means that non-linear function is locally not well behaved and smaller steps are needed — achieved by heurestically increasing the value of λ (example, multiply value by factor 10) and resolving normal equations. On other hand, if steps leads to reduced sum of squared residuals, it is accepted and state estimate is updated accordingly. In this case, λ is reduced (by dividing by factor 10), and algorithm repeats with new linearization point until convergence.

Dogleg Minimization

Powell's Dogleg (PDL) algorithm can be more effient alternative to LM. Disadvantage of Levenberg Marquardt Algorithm is that in case a step gets rejected, the modified information matrix has to be refactored, which is most expensive component of algorithm.

Key Idea → PDL separately computes GN and SD steps and then combine appropriately. If step gets rejected, the direction of steps are still valid and they can be combined in different way until a reduction in cost is achieved. Hence each update of the state estimate only involves one matrix factorization, opposed to several.

The combined step starts with the SD update, followed by a sharp bend toward GN update, but stopping at the trust region boundary. Unlike LM, PDL maintains an explicit trust region Δ within which we trust linear assumption.

The appropriateness of linear approximation is determined by gain ratio:

ρ = [ g(xt) − g(xt + Δ) ] / [ L(0) − L(Δ) ]

where L(Δ) = ATAΔ − ATb is linearization (non-linear quadratic) of cost function g at current estimate xt.

If ρ is small i.e ρ < 0.25, cost hasn't reduced as predicted by linearization and trust region is reduced. On other hand, if reduction is as predicted (or better) i.e ρ > 0.75, then trust region is increased depending on magnitude of update vector and step is accepted.

Note: Both Algorithms, GN and PDL, require the measurement Jacobian to be full rank so the ATA is invertible. When encountering under-constrained systems (numerically poor constrained) the LM Algorithm can be used instead even convergence speed might be impacted.
