Set Operations

  1. Transitivity: C ⊂ B and B ⊂ A ⇒ C ⊂ A
  2. Equality: A = B iff A ⊂ B and B ⊂ A
  3. Union: sum or union of two sets A and B → set whose elmts are all elements of A or of B or of both. A ∪ B or A + B. Union operation is commutative or associative: A + B = B + A; (A + B) + C = A + (B + C). B ⊂ A ⇒ A + B = A. A + A = A; A + {φ} = A; S + A = S.
  4. Intersection: product or intersection ⇒ all elements that are common to the sets A and B. A ∩ B or AB. Commutative, associative and distributive: AB = BA; (AB)C = A(BC); A(B+C) = AB + AC. A ⊂ B ⇒ AB = A. AA ⇒ A; A{φ} = {φ}; AS = A.
  5. Mutually Exclusive: Two sets A and B, are called Mutually Exclusive or Disjoint if they have no common elements, if AB = {φ}.
  6. Partition: Partition U of set s → collection of mutually exclusive subsets Ai of s whose union equals s. A1 + A2 + A3 + … + An = S, AiAj = {φ}, i ≠ j.
  7. Complements: complement Å of set A → consisting of all elements s that are not A. A + Å = S; AÅ = {φ}; ÅÅ = A; S̅ = {φ}; {φ}̅ = S. If B ⊂ A then B̅ ⊃ Å. If A = B then Å = B̅.

Theorem — De Morgan's Law:

Corollary: If in a set identity, we replace all unions by intersection, all intersection by unions, the sets s and {φ} by the sets {S} and {φ}, the identity is preserved.

Axioms of Probability

Assign to each event A of a space s a number P(A) which we call probability of an event A, satisfy the following conditions: I. P(A) ≥ 0. II. P(S) = 1. III. If AB = {φ}, then P(A + B) = P(A) + P(B). IIIa. If A1, A2, … are mutually exclusive, then P(A1 + A2 + …) = P(A1) + P(A2) + …

Properties of Probability:

  1. P(φ) = 0
  2. P(A) ≤ 1
  3. for any A and B, P(A + B) = P(A) + P(B) − P(AB) ≤ P(A) + P(B)
  4. If B ⊂ A, P(A) = P(B) + P(A B̅) ≥ P(B)

Probability Space

Space s (or Ω) → certain event. Elements → outcomes. Subsets → events. Empty set → impossible event. event {εi} consisting of single element εi in an elementary event.

Determination of Probabilities — Countable Spaces: Space s → N outcomes and N is finite no. Probability of all events P(εi) = Pi. of elementary event P{εi} = Pi. Pi ≥ 0; P1 + P2 + P3 + … + PN = 1. If s → N outcomes & probability Pi of elementary events are equal, Pi = 1/N. Probability of an event A consisting of r elements: P(A) = r/N = (Number of elementary events in A) / (Total Number of elementary events in S).

Non-Countable Space: s → set of all real numbers. Suppose α(x) is a function (PDF), ∫−∞∞ α(x) dx = 1, α(x) ≥ 0. Probability of Event {x ≤ xi} by integral: P{x ≤ xi} = ∫−∞xi α(x) dx. P{x1 < x ≤ x2} = ∫x1x2 α(x) dx.

Conditional Probability

Conditional Probability of an event A assuming M, P(A|M) is ratio P(AM)/P(M), P(M) ≠ 0.

Properties: 1. M ⊂ A ⇒ P(A|M) = 1. 2. A ⊂ M ⇒ P(A|M) = P(A)/P(M) ≥ P(A).

Remarks: 1. P(A|M) ≥ 0. 2. P(S|M) = 1. 3. AB = {φ} ⇒ P((A+B)|M) = P(A|M) + P(B|M).

Total Probability and Bayes' Theorem

Total Probability: If U = [A1, …, An] → partition of s and B is an arbitary event:

P(B) = P(B|A1) P(A1) + P(B|A2) P(A2) + … + P(B|An) P(An)

Bayes' Theorem: If U = [A1, …, An] → partition of s and B is an arbitary event:

P(Ai|B) = P(B|Ai) P(Ai) / [ P(B|A1) P(A1) + P(B|A2) P(A2) + … + P(B|An) P(An) ]

Independence

A and B are called Independent if P(AB) = P(A) P(B).

Properties: 1. A, B independent ⇒ Å, B independent. 2. A, B independent ⇒ Å, B̅ independent. 3. A, B independent ⇒ P(A|B) ≠ P(A). 4. If A is x% of the total, and the portion of A in B is x% of B, then A and B are independent.

Independence of Three Events: A1, A2, A3 are called Independent, if they are independent in pairs: P(AiAj) = P(Ai) P(Aj) and P(A1A2A3) = P(A1) P(A2) P(A3). Three events might be independent in pairs but not independent.

Combined Experiments, Bernoulli Trials, Permutations and Combinations

Bernoulli Trial: Sample space that contains as elements all possible orders or arrangements of group of objects. The different arrangement are called Permutations.

Theorem: Number of permutation of n distinct objects is n!, where n! = (n)(n−1)(n−2)…(3)(2)(1).

Theorem: Number of permutation of n distinct objects taken r at a time is n! / (n−r)!.

Number of ways of selecting r objects from n without regard to order. These selection are called Combinations: nCr = n! / (r!(n−r)!).

Success and Failure of an event A in n Independent Trials: Experiments, an event A with P(A) = p, P(Å) = q, p + q = 1. Pn(k) = P{A occurs k times in n trials} = nCk pk qn−k.

Concept of Random Variable

In a fair die experiment, if we assign six outcomes fi the number x(fi) = 10i i.e x(f1) = 10, … x(f6) = 60, then x(ε) is a random variable.

A random variable is function of outcome ε and satisfies: I. for every x, {x ≤ x} is an event. II. P{x = ∞} = 0, P{x = −∞} = 0.

Distribution and Density Function

Fx(x) = P{x ≤ x} is called cumulative distribution function of x. fx(x) = dFx(x)/dx is called density function of x.

Properties of Distribution Function:

  1. F(∞) = 1; F(−∞) = 0
  2. F(x) is non-decreasing function of x i.e F(x1) ≤ F(x2) if x1 < x2
  3. P{x > x} = 1 − F(x)
  4. F(x) is continuous from right i.e F(x) = limε→0 F(x+ε)
  5. P{x1 < x ≤ x2} = F(x2) − F(x1)
  6. P{x = x} = F(x) − F(x−) = limε→0 F(x−ε)
  7. P{x1 ≤ x ≤ x2} = F(x2) − F(x1−)

Random variable x is called Continuous Type if F(x) is continuous. Random variable x is called Discrete Type if F(x) is staircase.

Properties of Density Function: 1. f(x) ≥ 0. 2. F(x) = ∫−∞x f(y) dy. 3. ∫−∞∞ f(x) dx = 1. 4. P{x1 < x < x2} = ∫x1x2 f(x) dx.

Special Random Variables

Normal (Gaussian) Distribution

A random variable x → normal or gaussian if its density function is given by:

fx(x) = (1 / √(2πσ2)) e−(x−μ)2/2σ2

Properties: 1. G(∞) = 1. 2. (1/a√2π) ∫x1x2 e−(x−b)2/2a2 dx = G((x2−b)/a) − G((x1−b)/a). Central Limit Theorem states that under very general conditions the limiting distribution of the average of any number of independent random variables is normal.

Exponential Distribution

x is exponential with parameter λ if its density function is given by fx(x) = λe−λx for x ≥ 0, and 0 for x < 0 (Fx(x) = 1 − e−λx). If occurance of events over non-overlapping intervals are independent, such as arrival times of telephone calls or bus arrival times at bus stops, then waiting time distribution of these event can be shown exponential.

Memory less Property: Let s, t ≥ 0; consider events {x > s+t} and {x > s}. Then P{x > s+t | x > s} = P{x > s+t}/P{x > s} = e−λ(s+t)/e−λs = e−λt = P{x > t}. Only exponential distribution has this property.

Poisson Distribution

A random variable x is said to be Poisson distributed with parameter a if it takes 0, 1, …, n with P(x = k) = e−a ak/k!, k = 0, 1, 2. Thus f(x) = ∑i Pi δ(x−xi) = ∑k=0∞ e−a (ak/k!) δ(x−k).

Other special random variables in the notes include the Gamma, Uniform, Cauchy, Bernoulli (P{x=1} = P, P{x=0} = q = 1−p), Binomial (P(Y=k) = nCk pkqn−k, p+q = 1) and Geometric (P(x=k) = pqk−1, k = 1, 2, 3) distributions.

Asymptotic Approximations of Random Variable

Normal Approximation (Demoivre Laplace Theorem): If n is large, npq >> 1, then for k in √(npq) neighbourhood of np we have nCk pkqn−k = (1/√(2πnpq)) e−(k−np)2/2npq.

Poisson Approximation: e−a ak/k! is called Poisson Function. If n is large, p is very small, then for k of the order of np, we have nCk pkqn−k ≅ e−a ak/k! with a = np.

Law of Large Numbers: P( limn→∞ P(|k/n − P| ≤ ε) ) = 1 for any ε (Strong Law of Large Numbers).

Functions of One Random Variable

The random variable Y by Y = g(x). g(x) → deterministic function. Given Fx(x) and Y = g(x), find FY(y) and fY(y).

Determination of fY(y) — Fundamental Theorem: If Y = g(x), then fY(y) = fx(x1)/|g′(x1)| + … + fx(xn)/|g′(xn)| where x1, x2, … are root of y = g(x) i.e y = g(x1) = g(x2).

Mean and Variance

The expected value or mean of a discrete random variable is E{x} = ∑ xiPi where Pi = P{x = xi}. expected value or mean of a random variable is E{x} = ∫−∞∞ x fx(x) dx.

Conditional Mean: E{x|M} = ∫−∞∞ x f(x|M) dx for continuous. E{x|M} = ∑i xi P{x = xi|M} for discrete.

Variance: Variance of a random variable describes how spread the random variable is, greater variance, more spread, more random.

The variance of discrete random variable x is σ2 = ∫−∞∞ (x−η)2 fx(x) dx, σ → std. deviation of x. σ2 = ∑(xi−η)2 Pi. σ2 = E{x2} − η2. Variance is moment of inertia of f(x) around its center of gravity. Mean is center of gravity.

Moments: mn = E{xn} = ∫−∞∞ xn f(x) dx. Central Moments: μn = E{(x−η)n} = ∫−∞∞ (x−η)n fx(x) dx.

Chebyshev Inequality and Characteristic Function

Chebycheff Inequality — Theorem: for any ε > 0, P{|x−η| ≥ ε} ≤ σ2/ε2. Generalization: If f(x) = 0 for x < 0, then for any α > 0, P{x ≥ α} ≤ η/α.

Characteristic Function: φ(w) = ∫−∞∞ f(x) ejwx dx [Fourier Transform] is called Characteristic Equation of Random Variable x. Property of φ(w): |φ(w)| ≤ φ(0) = 1. Inverse Formula: f(x) = (1/2π) ∫−∞∞ φ(w) e−jwx dw.
